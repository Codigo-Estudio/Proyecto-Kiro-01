# Project Structure

```
kiro-introduction-starter-kit/
├── assets/           # Game audio and sprites
│   ├── game_over.wav # Game over sound effect
│   ├── ghosty.png    # Game sprite
│   └── jump.wav      # Jump sound effect
├── img/              # Screenshots and images
│   └── example-ui.png # Example UI screenshot
├── .gitignore        # Git ignore rules
├── LICENCE.md        # MIT-0 license
└── README.md         # Project documentation
```

## Folder Conventions

- **assets/**: Contains all game resources including audio (WAV) and images (PNG)
- **img/**: Contains documentation screenshots and UI reference images

## File Conventions

- Markdown files use `.md` extension
- Configuration files follow standard naming (e.g., `.gitignore`)
- No source code files present yet in this starter kit
